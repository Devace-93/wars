WARS

an open-source age-advancing real-time strategy game · 13 civilisations · 4 ages · random maps · scenario editor · computer players · online multiplayer

Server online.

Desktop

Windows, Linux and macOS builds (zip with wars, the console client wars-tui and the server).

Download Or build it: cargo run --release -p wars-desktop

Android

Debug APK, sideload it (allow installs from your browser or file manager).

Download APK Tap selects · drag box-selects · long press acts · two fingers pan · pinch zooms.

iPhone / iPad

Unsigned IPA; install it with Sideloader or Sideloadly and a free Apple ID.

Download IPA Not on the App Store.

Console

A terminal client with an action list and keyboard shortcuts for everything.

wars-tui is in every desktop download.

Play online

Multiplayer → play as a guest or log in with your 3m4 account → create a game and share the room code. Games run in lockstep on this server.

Accounts keep saves, replays and a place on the ladder.

Source

Everything is MIT-licensed Rust: one deterministic engine shared by all the clients.
