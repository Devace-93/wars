Host a game

  1. Open Wars on any device → Multiplayer.
  2. Play as a guest, or log in with your 3m4 account.
  3. Create game, pick the map and civilisations, add computer players if you like.
  4. Share the 6-letter room code (or tick Public so it shows below) and press Start.

Join a game: Multiplayer → Join by code, or pick one from the list.

Play online

Multiplayer → play as a guest or log in with your 3m4 account → create a game and share the room code. Games run in lockstep on this server.

Accounts keep saves, replays and a place on the ladder.

Run your own server

The same server this site runs, on your machine or a VPS. Point the clients at it in Options → Server URL.

git clone https://github.com/Devace-93/wars
cd wars && cp .env.example .env
make up          # Postgres + server on :8086
Guests work out of the box; 3m4 accounts need ACCOUNTS_URL in .env.
